# hospitalNoSQLLab2
Я дослідила 4 типи NoSQL систем і для практичної частини обрала документоорієнтовану базу MongoDB (як основну для складних оглядів) та Key-Value базу Redis (як допоміжну для сесій та черг)
MongoDB: документоорієнтована база для збереження ієрархічних електронних медичних карток (ClinicalEncounters).
MS SQL Server: реляційне порівняння через транзакційну вставку у 2 зв'язані таблиці та вибірку з JOIN.
Redis: Key-Value сховище (сесії лікарів із TTL, електронна черга пацієнтів FIFO через List, моніторинг ліжок через Hash).
Результат бенчмарку: запис у MongoDB виявився у ~15-17 разів швидшим за реляційну БД.
